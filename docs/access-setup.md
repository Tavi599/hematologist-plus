# Доступ до статей: що зробити власнику проєкту

Статті довідника читає лише той, хто увійшов. Публічна частина (калькулятор, схеми, перелік
нозологій, коди МКХ-10, джерела) залишається відкритою.

## 1. Вимкнути самостійну реєстрацію

Панель Supabase → **Authentication → Sign In / Providers → Email**:

- `Enable Email provider` — увімкнено;
- **`Allow new users to sign up` — вимкнути**. Без цього будь-хто міг би створити собі акаунт;
- `Confirm email` — можна вимкнути, бо акаунти створюєте ви вручну.

## 2. Створити 4 акаунти

**Authentication → Users → Add user → Create new user**: пошта й пароль, `Auto Confirm User` — так.
Пароль передайте колезі особисто й попросіть змінити при нагоді.

Скидання пароля: **Users → ⋯ → Send password recovery** або задати новий пароль вручну. Безкоштовний
план обмежує кількість листів, тож надійніше задавати пароль у панелі.

## 3. Перевірити

1. Відкрийте https://tavi599.github.io/hematologist-plus/#/diseases/dlbcl **не увійшовши** — має бути
   «Текст статті доступний лише після входу».
2. Увійдіть — з'явиться текст статті, а в шапці сайту — ваша пошта й кнопка «Вийти».
3. У репозиторії: `npm run db:check-rls` має написати `disease_articles  not readable without a session`.

## Як оновлювати статті

Тексти лежать у приватному репозиторії (`../Hematologist_plus_content`), поряд із публічним:

```
Hematologist_plus/            публічний: код, препарати, схеми, нозології
Hematologist_plus_content/    приватний: diseases/<id>/article.uk.md, article.en.md
```

Перевірка і генерація SQL:

```bash
npm run data:validate -- --content "../Hematologist_plus_content"
npm run data:sync -- --content "../Hematologist_plus_content" --sql apply.sql
```

Отриманий `apply.sql` містить **текст статей**. Його виконують лише через SQL Editor Supabase і
ніколи не завантажують у публічний репозиторій — навіть у тимчасову гілку.

Щоб зробити з теки `Hematologist_plus_content` приватний репозиторій GitHub: створіть **приватний**
репозиторій, далі `git remote add origin <url>` і `git push -u origin main`. Колегам доступ до нього
не потрібен — вони читають статті на сайті.

## Що бачить стороння людина

| Дані | Без входу |
|---|---|
| Калькулятор, схеми, дози, розведення | видно |
| Перелік нозологій, коди МКХ-10, дерево лікування | видно |
| Джерела (протоколи, дизайни відділення) | видно |
| **Текст статей** | **не видно: таблиця порожня для незалогінених** |
| Дані пацієнта | ніколи нікуди не надсилаються |
