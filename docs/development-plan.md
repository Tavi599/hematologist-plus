## Етап 1. Модуль розрахунків (`src/domain`)

**Мета:** уся медична математика в чистих функціях, покритих тестами. Інтерфейсу поки немає.

Задачі:
- [x] `bsa.ts`: Mosteller, обмеження BSA 2,0 m², подвійний результат.
- [x] `renal.ts`: Cockcroft-Gault (вік, стать, вага, креатинін, одиниці µmol/L ↔ mg/dL); Calvert для AUC.
- [x] `dosing.ts`: одиниці `mg_m2`, `mg_kg`, `mg_flat`, `auc`; `capMg`; редукція % на курс і на препарат.
- [x] `rounding.ts`: округлення до 1 mg, обмеження вмістом флакона (вимкнено до калібровки), збереження дози без округлення.
- [x] `presentations.ts`: кількість флаконів/таблеток на введення і сумарно на курс.
- [x] `infusion.ts`: об'єм розчинника за допустимою концентрацією, вибір стандартного флакона розчинника, швидкість (mL/год, крап/хв).
- [x] `schedule.ts`: дні курсу → календарні дати; погодинна розстановка введень (початок дня, послідовність, тривалості, ручний зсув).
- [x] `warnings.ts`: перевірка діапазонів даних пацієнта, підказки щодо редукції (без зміни дози).
- [x] Кожна функція повертає ланцюжок розрахунку для показу в інтерфейсі.
- [x] Усі параметри за замовчуванням зібрані в `src/domain/config.ts`.
- [x] Тести на прикладах, порахованих вручну (78 тестів, покриття 99%).
- [ ] ⏳ **Калібровка — перенесено на етап 5**, виконується на готових макетах листів призначень. Перелік параметрів: [calibration.md](calibration.md).

✅ Покриття `src/domain` ≥ 95% (виконано). Еталонні приклади з макетів — після калібровки на етапі 5.

2. Спільний сеанс у Chrome (20–30 хв): Google Таблиця «HD ARA-C» → структура листа для етапу 4а; папка з бланками → макети для етапу 5; eviQ/NCCN → звірка доз уже введених схем.
