# Калібровка модуля розрахунків

Статус: **не відкалібровано** (2026-09-13).

Формули в `src/domain/` реалізовані за загальноприйнятими джерелами й перевірені тестами на прикладах, порахованих вручну. Правила відділення ще не звірені. Калібровка відбудеться **на готових макетах листів призначень** (етап 5): результати калькулятора порівнюються з реальними листами, розбіжності виправляються в `src/domain/config.ts` або у формулах, а кожен звірений лист стає еталонним тестом.

⚠️ До завершення калібровки калькулятор не використовується для реальних пацієнтів.

## Що калібрувати

| # | Параметр / правило | Поточне значення | Де в коді |
|---|---|---|---|
| 1 | Формула BSA | Mosteller | `bsa.ts` |
| 2 | Обмеження BSA для другого варіанта дози | 2,0 m² | `config.ts → bsaCapM2` |
| 3 | Перерахунок креатиніну µmol/L → mg/dL | ÷ 88,4 | `config.ts → creatinineUmolPerMgDl` |
| 4 | Вага в Cockcroft-Gault | фактична | `renal.ts → cockcroftGault` |
| 5 | Коефіцієнт для жінок у Cockcroft-Gault | 0,85 | `config.ts → cockcroftGaultFemaleFactor` |
| 6 | Верхня межа GFR у формулі Calvert | 125 mL/min | `config.ts → carboplatinGfrCapMlMin` |
| 7 | Порядок: максимальна доза (cap) → редукція | спершу cap, потім % | `dosing.ts → calculateDose` |
| 8 | Редукція препарату vs редукція курсу | % препарату замінює % курсу | `dosing.ts → effectiveReductionPercent` |
| 9 | Крок округлення | 1 mg | `config.ts → doseRoundingStepMg` |
| 10 | Округлення до вмісту флакона: допуск, напрям | вимкнено (`null`) | `config.ts → vialRoundingTolerancePercent`, `rounding.ts` |
| 11 | Підбір флаконів | мінімальні залишки, потім мінімум флаконів; флакони не діляться між введеннями | `presentations.ts` |
| 12 | Об'єм розчинника | найменший стандартний флакон у межах концентрації; об'єм препарату додається, якщо відома концентрація розчину | `infusion.ts` |
| 13 | Краплинний фактор | 20 крапель/mL | `config.ts → dropFactorGttPerMl` |
| 14 | Розклад дня: інтервали, паралельні інфузії | послідовно, без паралельних | `schedule.ts` |
| 15 | Пороги підказок щодо редукції | КК < 60 mL/min, вік ≥ 70, білірубін > 34 µmol/L | `config.ts → warningThresholds` (далі — з довідника препаратів) |
| 16 | Допустимі діапазони даних пацієнта | вік 18–110, зріст 120–230 cm, вага 30–250 kg, креатинін 20–1500 µmol/L | `config.ts → patientLimits` |

## Порядок калібровки

1. Для кожного макета листа внести вхідні дані пацієнта та схему.
2. Порівняти дози, флакони, об'єми, швидкості, дати й час з макетом.
3. Кожну розбіжність класифікувати: помилка формули / інше правило відділення / помилка в макеті.
4. Виправити параметр або формулу, оновити цю таблицю.
5. Додати макет як еталонний тест (`src/domain/__fixtures__/`).
6. Коли всі пункти звірені — змінити статус угорі на «відкалібровано» з датою.
